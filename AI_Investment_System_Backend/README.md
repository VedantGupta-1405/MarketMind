This project presents an AI-based Investment Decision System that combines machine learning and sentiment analysis to improve stock market prediction. By utilizing historical data and analyzing news sentiment, the system is able to generate more informed and data-driven investment recommendations.

The integration of multiple components such as ML models, sentiment analysis, backend processing, and an interactive dashboard ensures a complete and practical solution. The system simplifies complex analysis and provides clear outputs in the form of Buy, Hold, or Sell decisions along with confidence scores.

Overall, the project demonstrates how combining numerical and textual data can enhance decision-making in financial systems and offers a scalable approach for future improvements.
